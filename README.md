# Betelgeuse — інтелектуальна автономна посадка першого ступеня

**v2.0** · дипломний GNC-симулятор (Unity URP) · протокол Monte-Carlo **v15**

**Тема:** Розроблення інтелектуальної системи автономної посадки **першого ступеня** ракети-носія
на основі нечіткої логіки та машинного навчання.

Симулятор GNC 1-го ступеня (аналог Falcon 9: суха маса 25.6 т, Ø 3.66 м, посадковий двигун 845 кН,
Isp 282 с) у земних умовах (Earth LZ): порівняння PID / Fuzzy / Neural / Hybrid.

## Режими керування

| | Режим | Закон |
|---|--------|--------|
| A | **PID** | hover + PID по вертикальній швидкості; PID орієнтації (D — гіроскоп) |
| B | **Fuzzy** | Sugeno-0: база 5×5 для тяги (h × \|Vy\|) і база 5×5 для TVC (e × ė) |
| C | **Neural** | профіль soft-landing + **MLP 5→8→2**, ваги навчені **ES(1+λ)** офлайн |
| D | **Hybrid** ★ | закон B + окремо навчений MLP-residual (Neuro-Fuzzy); residual OFF ⇒ D ≡ B |

Бічне наведення, навігація, safety-шар і фізика — **спільні** для всіх режимів (чесне порівняння).
MLP коригує тягу і масштаб бічного наведення; у польоті та Monte-Carlo ваги заморожені.

## Результати (протокол v15, N=100 на алгоритм, seed 42, paired)

Вітер 15 м/с, ±8 % маси, ±8° кута, ±25 м точки входу, шум навігації, h₀ = 1800 м, |Vy₀| = 72 м/с.

| | PID | Fuzzy | Neural | Hybrid | Hybrid, residual OFF |
|--|--|--|--|--|--|
| Успішні посадки | 73 % | 78 % | **100 %** | **100 %** | 78 % |
| Сер. промах, м | 16.4 | 23.0 | 4.3 | **2.5** | 23.0 |
| Сер. \|Vh\|, м/с | 4.45 | 3.68 | 0.22 | **0.18** | 3.68 |

За помірних умов (вітер 5 м/с) усі чотири алгоритми мають 100 %. Різниця з’являється, коли вітер
наближається до межі можливостей фіксованих законів (≈14 м/с): навчена MLP утримує 100 % до 17 м/с
(див. `Results/robustness_wind.png`).

Навчання (валідація, 200 сценаріїв, вітер 0–18 м/с): Neural — вартість 0.766 → 0.225, успіх 88.5 → 100 %;
Hybrid — 0.699 → 0.211, 91.0 → 100 %.

## Швидкий старт

1. Unity **6000.x** (URP) → `Assets/Scenes/SampleScene.unity` → **Play**.
2. **`F1`** довідка · **`M`** демо · **`1–4`** метод · **`Space`** старт · **`B`** протокол · **`P`** Monte-Carlo · **`E`** експорт.
3. Навчання: `Tools\HeadlessSim\build.cmd`, потім `Tools\HeadlessSim\run.cmd train --mode neural|hybrid`.

## Критерії soft-landing

|Vᵧ| < **3.5** м/с · нахил < **7°** · промах < **40** м · |Vₕ| < **6.5** м/с
